## Installation Checklist

Before installing Jenny Mod:

1. Verify your Minecraft version.
2. Install the correct Forge version.
3. Download the required files.
4. Place the mod file inside the mods folder.
5. Launch Minecraft using the Forge profile.

## Common Problems

### Jenny Mod Not Showing Up

Possible causes:

- Incorrect Minecraft version
- Incorrect Forge version
- Mod file placed in wrong folder

### Minecraft Crashes After Installing Jenny Mod

Possible causes:

- Mod conflicts
- Missing dependencies
- Unsupported version combinations

### Installation Errors

Check:

- Forge installation
- Java version
- Mod compatibility

## Compatibility Tips

Always match:

- Minecraft Version
- Forge Version
- Jenny Mod Version

Using incompatible versions is one of the most common causes of installation problems.
